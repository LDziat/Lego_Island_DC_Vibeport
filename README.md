# LEGO Island Dreamcast - Slop Style

That's right another port of the classic PC game Lego Island is dropping. This time it's for everyonw's favorite, the SEGA Dreamcast!
The thing that makes this project unique is that the entire Dreamcast wrapper has been written by Google Antigravity. This has been an experiment to see just how far AI assisted programming has come. The results are frankly impressive and speak for themselves. While it's taken somewhere in the ballpark of 36,000,000 input and 800,000 output tokens we have gotten an engine that provides the earliest signs of playability.
This has been tested to work in redream with a lengthy initial loading time. I have yet to perform any tests on actual hardware.

This is not to be taken as a serious project. While it will continue to receive occasional updates this will never become a complete port. The system specs are rather tight and the current approach has a significant amount of overhead that would need to be manually addressed. This is just a fun experiment showing how just far you can get without touching the code.
